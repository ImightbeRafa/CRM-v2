================================================================================
🐛 TROUBLESHOOTING
================================================================================

ISSUE: "NEXT_PUBLIC_TILOPAY_API_KEY is undefined"
SOLUTION: 
  - Add to .env file
  - Restart dev server (npm run dev)
  - Hard refresh browser (Ctrl+Shift+R)

ISSUE: "tilopayCustomerId does not exist in type"
SOLUTION:
  - Run: npx prisma generate
  - Restart TypeScript server in VS Code

ISSUE: Checkout modal doesn't appear
SOLUTION:
  - Check browser console for errors
  - Verify BillingDashboard imported component
  - Check React DevTools for state

ISSUE: SDK doesn't load
SOLUTION:
  - Check CSP headers allow sdk.tilopay.com
  - Verify internet connection
  - Check Tilopay status page

ISSUE: Payment fails
SOLUTION:
  - Verify test mode is enabled
  - Use correct test cards
  - Check backend logs for API errors
  - Verify Tilopay credentials

ISSUE: Webhook not received
SOLUTION:
  - Verify webhook URL is publicly accessible
  - Check webhook secret matches
  - Review webhook logs in database
  - Test with Tilopay dashboard webhook simulator
