HOW SDK v1 WORKS
----------------
1. User clicks "Iniciar Pago Seguro"
2. Backend generates SDK token (/api/tilopay/create-subscription-token)
3. Frontend calls window.Tilopay.Init() with token
4. User clicks "Pagar ₡10,000 / mes"
5. Frontend calls window.Tilopay.startPayment()
6. SDK redirects to Tilopay hosted page
7. User enters card details on Tilopay site
8. Tilopay processes payment with subscription: 1
9. Tilopay redirects back to /api/tilopay/callback
10. Callback updates tenant subscription status

Benefits:
  ✅ Works in localhost and production
  ✅ PCI compliant (card data never touches our server)
  ✅ Proven, stable SDK (not experimental v2)
  ✅ Supports recurring subscriptions
  ✅ 3DS authentication built-in
