TROUBLESHOOTING
================================================================================

If SDK doesn't load:
  - Check CSP headers in browser DevTools
  - Verify URL: https://app.tilopay.com/sdk/v2/sdk_tpay.min.js
  - Hard refresh: Ctrl+Shift+F5

If 404 on token generation:
  - Verify using /api/v1 (not v2!)
  - Verify hashVersion: "V2" in payload
  - Check Integration-Key header (not X-API-KEY)
  - Verify credentials in .env.local

If "Faltan parametros":
  - Token must not be empty
  - All required fields must be present
  - hashVersion must be "V2"

If payment fails:
  - Check 3DS response container exists
  - Verify all required HTML elements have correct IDs
  - Check console for specific error messages
