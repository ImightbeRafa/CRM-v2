🔄 PAYMENT FLOW
================================================================================

1. User clicks "Iniciar Pago Seguro"
   └─> Frontend calls /api/tilopay/create-subscription-token

2. Backend generates SDK token
   └─> Returns: token, email, firstName, lastName

3. Frontend calls await Tilopay.Init({...})
   └─> SDK initializes with all required parameters
   └─> Returns: {message: "Success", methods: [...], cards: [...]}

4. SDK displays card form (embedded, no redirect)
   └─> User enters card details in form fields

5. User clicks "Pagar ₡10,000 / mes"
   └─> Frontend calls await Tilopay.startPayment()

6. SDK processes payment with 3DS if needed
   └─> Uses #responseTilopay div for 3DS iframe
   └─> subscription: 1 saves card to Tilopay

7. Payment completes
   └─> Webhook sent to /api/tilopay/webhook-repeat
   └─> Tenant subscription activated
   └─> Success callback executed
