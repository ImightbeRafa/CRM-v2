================================================================================
🔍 KEY DISCOVERIES
================================================================================

1. 🔑 Authentication Method
   - Tilopay uses JWT Bearer tokens, NOT Basic Auth
   - Endpoint: POST /api/v1/loginSdk
   - Payload: { "apiuser": user, "password": pass, "key": apiKey }
   - Response: { "access_token": "...", "expires_in": "..." }

2. 🔑 GetTokenSdk Endpoint DOES NOT EXIST
   - Attempted 8 different endpoint variations
   - All returned 404 Not Found
   - /GetTokenSdk, /getTokenSdk, /gettokensdk, etc.
   - Conclusion: No separate token generation for SDK v2

3. 🔑 Bearer Token Usage
   - Bearer token from /loginSdk used for SDK Init()
   - SDK accepts the token without errors
   - Init succeeds, but payment fails
   - Possible: Bearer token is for API calls, not SDK payments

4. 🔑 DOM Element Timing
   - SDK requires HTML elements to exist BEFORE Init()
   - Fixed by showing form first, then initializing
   - Original error: "Cannot read properties of null (reading 'addEventListener')"
   - Solution: setSdkInitialized(true) before SDK Init()

   - SDK might need different token or no token at all

   - Form validation might be preventing submission
