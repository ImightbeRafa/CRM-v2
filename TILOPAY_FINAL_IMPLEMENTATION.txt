Frontend (User clicks "Iniciar Pago Seguro"):
──────────────────────────────────────────────

   Body: { planId: 'basic', amount: 10000, currency: 'CRC', recurring: true }

Backend (create-subscription-token API):
────────────────────────────────────────
1. Authenticate user with NextAuth
2. Get tenant info from Prisma
3. Login to Tilopay → Get JWT
4. Call /GetTokenSdk with Bearer token
5. Return { token: 'tk_...' } to frontend

Frontend (SDK Initialization):
───────────────────────────────
1. Receive token from backend
2. Initialize SDK v2:
   window.Tilopay.Init({
     token: 'tk_...',
     currency: 'CRC',
     amount: 10000,
     subscription: 1,
     hashVersion: 'V2'
   })
3. Display card form
4. User enters card details
5. Call window.Tilopay.startPayment()
6. SDK processes payment and saves card token

Webhook (Tilopay → Your Server):
─────────────────────────────────
1. POST /api/tilopay/webhook
   Body: { 
     event: 'payment.approved',
     referencia: 'tenantId-planId-timestamp',
     transaccion_id: 'tx_123',
     monto: 10000
   }
2. Verify webhook signature
3. Update tenant subscription status
4. Create billing transaction record
5. Return 200 OK

Monthly Renewal (Automatic):
────────────────────────────
1. Tilopay charges saved card
2. POST /api/tilopay/webhook
   Body: { 
     event: 'subscription.renewed',
     referencia: 'tenantId-planId-timestamp',
     transaccion_id: 'tx_456',
     monto: 10000
   }
3. Webhook extends subscription period
4. Creates billing transaction
5. User's access continues

TROUBLESHOOTING

If Login Fails (401):

  - Check credentials: usuario and password
  - Verify test mode vs production

If GetTokenSdk Fails (404):
  - Terminal will show all 8 endpoints tried
  - Check Bearer token in Authorization header
  - Verify hashVersion: "V2" in payload

If SDK Doesn't Load:
  - Hard refresh: Ctrl+Shift+F5
  - Check CSP in browser DevTools
  - Verify SDK URL: app.tilopay.com/sdk/v2/sdk_tpay.min.js

If Webhook Not Received:
  - Check Tilopay admin panel webhook config
  - Verify URL: https://yoursite.com/api/tilopay/webhook
  - Test locally with ngrok or similar
  - Check webhook signature verification
