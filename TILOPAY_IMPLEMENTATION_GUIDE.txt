TROUBLESHOOTING
================================================================================

ISSUE: "tilopayCustomerId does not exist in type"
SOLUTION: Run `npx prisma generate` after migration

ISSUE: SDK not loading
SOLUTION: Check browser console, ensure Script tag loads from Tilopay CDN

ISSUE: Payment token generation fails
SOLUTION: 
  - Verify TILOPAY_API_KEY, TILOPAY_USER, TILOPAY_PASSWORD in .env
  - Check Tilopay API status
  - Review backend logs for API errors

ISSUE: Webhook not received
SOLUTION:
  - Verify webhook URL is publicly accessible (not localhost)
  - Check TILOPAY_WEBHOOK_SECRET matches Tilopay dashboard
  - Use ngrok for local testing: ngrok http 3000
  - Configure webhook in Tilopay dashboard with ngrok URL

ISSUE: Subscription created but tenant not upgraded
SOLUTION:
  - Check webhook logs: /api/webhook-logs
  - Verify webhook signature validation
  - Check database for billingTransaction records
  - Review audit logs
