## Sistema de Clientes

BetsyCRM gestiona clientes de forma inteligente. Cada vez que creas un pedido, el sistema registra los datos del cliente automáticamente para futuras compras.

## Clientes Automáticos

Cuando creas un pedido con un nombre de cliente nuevo, BetsyCRM:

1. **Crea un registro de cliente** automáticamente con los datos proporcionados (nombre, teléfono, email, dirección)
2. **Asocia el pedido** al registro del cliente
3. **Mantiene un historial** de todos los pedidos del cliente

La próxima vez que escribas el mismo nombre en el formulario de ventas, los datos se autocompletarán.

<Callout type="tip">
El autocompletado busca por nombre del cliente. Si un cliente usa nombres ligeramente diferentes en cada compra (ej: "Juan Pérez" vs "Juan P."), se crearán registros separados. Intenta ser consistente con los nombres.
</Callout>

## Clientes Frecuentes

BetsyCRM identifica automáticamente a los clientes que compran con mayor frecuencia y los marca como "frecuentes". Esto te permite:

- **Priorizar** la atención de clientes leales
- **Autocompletar** más rápido sus datos
- **Ver estadísticas** de compra por cliente

### Ver Clientes Frecuentes

<Steps>
  <Step title="Ir a Configuración">Navega a **Configuración** → **Clientes**.</Step>
  <Step title="Lista de clientes">Verás la lista de todos tus clientes ordenados por cantidad de pedidos.</Step>
  <Step title="Detalles">Haz clic en un cliente para ver su historial de pedidos, total gastado y productos comprados.</Step>
</Steps>

## Productos Frecuentes

De manera similar a los clientes frecuentes, BetsyCRM también rastrea qué productos se piden más. Esta información está disponible en la configuración y te ayuda a:

- Identificar tus productos más populares
- Planificar inventario
- Detectar tendencias de compra

## Datos del Cliente

| Campo | Fuente | Uso |
|-------|--------|-----|
| **Nombre** | Formulario de venta | Identificación y autocompletado |
| **Teléfono** | Formulario de venta | Contacto y envío |
| **Email** | Formulario de venta | Notificaciones |
| **Dirección** | Formulario de venta | Envío y generación de guías |
| **Provincia** | Formulario de venta | Estadísticas por zona |
| **Cantidad de pedidos** | Automático | Identificar frecuentes |
| **Total gastado** | Automático | Valor del cliente |

<Callout type="info">
Los datos de clientes se almacenan de forma segura y aislada por tenant. Cada negocio solo ve sus propios clientes.
</Callout>

## Privacidad

BetsyCRM cumple con las mejores prácticas de privacidad de datos:

- Los datos de clientes no se comparten entre tenants
- Puedes eliminar registros de clientes si lo solicitan
- No se almacenan datos de pago de los clientes
